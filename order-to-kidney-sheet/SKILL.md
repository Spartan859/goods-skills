# 排表/肾表 XLSM 生成

将已经结构化的排表或肾表数据转换为宏兼容的 `.xlsm`。工作簿包含上半部排表、下半部肾表和原汇总宏。

原始 QQ 抢单评论不在此技能内解析。遇到未排单的评论文本时，先使用 `qq-comment-to-sheet` 生成排表，再回到本技能。

## 判断输入模式

先判断用户提供的是哪一类数据：

- `arrangement`：包含商品、各配位用户名和价格信息。生成上下两部分。
- `kidney`：已经包含 `cn` 与 `国际金额`。上半部排表留空，下半部统一输出 `CN、应付、点数`。

支持表格文件、粘贴的文本表格或图片。逐项读取以下字段：

- 排表：商品名、第1配至第10配、单价、汇率、调价或固定价格。
- 肾表：CN、国际金额、可选点数。

不要猜测缺失或模糊的 CN、金额、商品或槽位。发现歧义时，列出具体行和字段并停止生成。

## 规范化数据

将识别结果写入临时 JSON，字段和校验规则见 [input-schema.md](references/input-schema.md)。

排表模式要点：

- 每个商品最多 10 个配位。
- 有占用的商品必须提供固定 `price`，或同时提供 `unit_price` 与 `exchange_rate`。
- `adjustment` 可选，默认 0。
- 价格公式为 `单价 × 汇率 + 调价`。

直接肾表模式要点：

- 只提供 `kidney_rows`，不要提供商品或价格。
- `amount` 映射为`应付`。
- 未提供 `points` 时保留空单元格，不填 0 或短横线。
- 重复 CN 按首次出现顺序聚合并求和。

## 依赖

生成脚本需要 Python 3.10+ 与 `openpyxl`。先用 `python3 -c "import openpyxl"` 检查运行环境。

## 生成工作簿

在技能目录运行：

```bash
python3 scripts/build_order_kidney_workbook.py \
  --input normalized.json \
  --output "标题-排表-肾表.xlsm"
```

直接肾表模式的推荐输出名称为 `标题-肾表.xlsm`。未提供标题时分别使用：

- `排表-肾表.xlsm`
- `肾表.xlsm`

生成器自动使用 `assets/order-kidney-template.xlsm`，保留表格样式、价格公式和汇总宏。不要自行加入二维码、个人信息、外部链接或额外宏。

## 汇总语义

排表模式的肾表复刻原汇总宏：

1. 按第1配、第2配至第10配的列顺序，再按商品行顺序扫描。
2. CN 首次出现时建立肾表行。
3. 应付为所有占用槽位对应价格之和，保留计算精度并显示两位小数。
4. 点数为占用槽位数量。

直接肾表模式仍保持一行一个 CN。若输入已含点数则累加，全部未提供时保持空白。

## 输出验收

生成后至少确认：

- 文件为有效 `.xlsm`，并包含 `xl/vbaProject.bin`。
- 上半部包含 `第1配` 至 `第10配`，下半部包含 `CN、应付、点数`。
- 排表 Table 和肾表 Table 的范围覆盖全部数据且互不重叠。
- 工作簿无图片、二维码或示例个人信息。
- 价格公式存在，OpenXML 压缩结构完整。

宏启用文件打开时可能触发 Excel 安全提示。只使用本技能内置且已审阅的汇总宏，不要执行来源不明的宏。

完整输入和处理示例见 [examples.md](references/examples.md)。
