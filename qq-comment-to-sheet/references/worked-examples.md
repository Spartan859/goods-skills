# QQ 评论排单转表格：完整示例

## 示例一：优先单、普通单与固定排序

输入：

```text
09:01 | AB | 千2
09:02 | CD | 提善1
09:03 | EF | 千3
```

处理过程：

1. 优先分配 `提善1`，CD 占用“善”的槽位 1。
2. 再按时间分配普通请求：AB 占用“千”的槽位 1 至 2，EF 占用“千”的槽位 3 至 5。

预期输出：

| 商品 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 千 | AB | AB | EF | EF | EF |  |  |  |  |
| 曜 |  |  |  |  |  |  |  |  |  |
| 梨 |  |  |  |  |  |  |  |  |  |
| 丸 |  |  |  |  |  |  |  |  |  |
| 露 |  |  |  |  |  |  |  |  |  |
| 善 | CD |  |  |  |  |  |  |  |  |
| 黛 |  |  |  |  |  |  |  |  |  |
| 鞠 |  |  |  |  |  |  |  |  |  |
| 南 |  |  |  |  |  |  |  |  |  |

## 示例二：连打缩写与“凹”

输入：

```text
10:00 | AB | 千曜2
10:01 | CD | 善梨凹
```

解析结果：

- AB：`千2`、`曜2`
- CD：`善凹`、`梨凹`

预期分配：

- 千槽位 1 至 2：AB
- 曜槽位 1 至 2：AB
- 善槽位 1 至 9：CD
- 梨槽位 1 至 9：CD

其余商品保持空行，所有 9 个商品行均须输出。

## 示例三：超售

输入：

```text
11:00 | AB | 千8
11:01 | CD | 千3
```

预期分配：

- 千槽位 1 至 8：AB
- 千槽位 9：CD
- CD 剩余 2 个请求不分配

表格后追加：

```text
超售未分配：CD-千×2
```
